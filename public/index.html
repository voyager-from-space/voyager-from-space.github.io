blindsanitize

Checks a paper's source, PDF and supplementary files for anything that gives away its authors before a double-blind submission, and hands back cleaned copies.

Open blindsanitizeCode

61 → 5

A test submission with 61 planted identity strings came back with none left in the source or the PDF's hidden data. The 5 left are in code files, which it flags for you instead of editing.

Measured 19 Nov 2026. A pattern-based scan, not a guarantee. The optional build check downloads about 177 MB the first time.

maketitle

Opens an arXiv paper's LaTeX source in an editor and compiles it in your browser tab.

Open maketitleCode

4.76 s

Edit the title of paper 1706.03762, press Ctrl+Enter, and a new PDF is on screen in 4.76 seconds with TeX Live cached.

Measured 19 Nov 2026. The first visit downloads 166.5 MB for a plain article, up to 416.6 MB for papers with many packages. After one compile it works offline.

papershed

Cleans a LaTeX zip before you post it: strips comments, photo GPS and PDF metadata, and flags possible leaks.

Open papershedCode

73% smaller

Its own planted sample zip went from 4.6 MB to 1.3 MB. It flagged 9 possible leaks and removed 14 files and 9 comments.

Measured 19 Nov 2026. The optional compile check downloads about 177 MB the first time.

One route for a paper

The tools were built to be used in this order, and each one works on its own.

  1. texdietSlim the project so it compiles faster.
  2. papershedClean the zip before you post it.
  3. maketitleOpen an arXiv paper's LaTeX source and compile it in the tab.

Submitting double-blind? blindsanitize checks the source, PDF and extra files for anything that points to the authors.
